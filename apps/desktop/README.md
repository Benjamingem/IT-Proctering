# Windows desktop agent

After Employee sign-in, the agent reports operating-system idle duration and, on Windows, foreground application/window-title changes. Titles can reveal webpage or document names and are shown in the employee Activity timeline. Admin sessions report only their own current SSID for the network settings view. On Windows, the agent reads the SSID with `netsh wlan show interfaces`. The reported SSID must exactly match an active Admin allowlist entry for an employee to be Available or Away; otherwise the session remains Offline. When the server reports Away, a small desktop banner appears and stays visible until status returns to Available; the tray tooltip also shows current state. Windows lock/unlock is reported as Away/Available, and system suspend stops heartbeats so the server can mark the session Offline.

An Admin can add exact SSID strings under Policies. Match state is informational because SSIDs can be spoofed. Camera check-ins require the Admin to enable them, the employee to opt in, an exact approved SSID match, a current Away status, and camera permission. The employee sees a disclosed countdown and camera-active indicator before one still photo is captured; capture can be cancelled. Photos are encrypted, limited to one per Away period, visible only to the employee and authorized Admins, and deleted after 30 days. No audio or continuous video is captured.

The employee app has its own Windows sign-in and status interface; it does not embed the web dashboard. It reports current Available/Away status, today's activity summary, office-network match, and camera consent/check-in state. Admins continue to manage the team and policies in the web dashboard. Start the API first, then run `npm run desktop` from the project root. Closing the app window hides it to the system tray; monitoring continues while the app is running. Use Sign out or Quit and end session to stop monitoring and end the server session. Employees can opt into Start with Windows in the app. Set `EAM_API_ORIGIN` to the API origin when it is not `http://localhost:3000`.

To create a Windows portable ZIP, run `npm run build:desktop` from the project root. Extract it to a managed location and deploy it through the organization's authorized endpoint-management process. This starter does not produce an installer or enable startup automatically.

The agent reports the current idle state after a network reconnect; it does not fabricate timestamps for transitions that could not be observed while disconnected. The server marks a live session Offline after 45 seconds without an agent heartbeat. Verify the idle timer, lock/unlock and suspend/resume behavior, startup opt-in, and packaging on supported Windows 10/11 machines before deployment.
